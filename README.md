# ✍️ Firma Simple

**Firma documentos sin cuentas, sin subir archivos y sin complicaciones.**

Una herramienta web ligera para crear tu firma manuscrita y firmar documentos PDF directamente desde el navegador.

Todo ocurre **localmente en tu dispositivo**. Tus documentos y tu firma no se envían a ningún servidor.

🌐 **Demo:** `https://petcuraapp.github.io/firmador-pdf/`

---

## ✨ ¿Qué hace?

### Crear una firma

Dibuja tu firma directamente con:

* 📱 El dedo en tu teléfono o tablet
* 🖊️ Un lápiz digital
* 🖱️ El mouse en tu computador

La firma se puede exportar como **PNG con fondo transparente**, lista para utilizar en cotizaciones, órdenes de compra, formularios y otros documentos.

### Firmar un PDF

También puedes abrir un PDF directamente en el navegador y:

* Crear una firma nueva
* Reutilizar una firma guardada
* Arrastrarla hasta la posición deseada
* Cambiar su tamaño
* Firmar diferentes páginas
* Descargar el PDF resultante

Sin modificar el documento original.

---

## 🔒 Privacidad

**Tus documentos no se suben a ningún servidor.**

El procesamiento se realiza directamente en el navegador mediante JavaScript.

La firma guardada permanece en el almacenamiento local del navegador (`localStorage`) del dispositivo.

No hay:

* ❌ Registro
* ❌ Inicio de sesión
* ❌ Base de datos
* ❌ Tracking
* ❌ Subida de documentos
* ❌ Backend
* ❌ Suscripción
* ❌ Marca de agua

Abres, firmas y guardas.

## 🚀 Uso

No requiere instalación.

Puedes utilizar la versión publicada mediante GitHub Pages o ejecutar el proyecto directamente.

```text
1. Descarga el repositorio
2. Abre el archivo HTML
3. Firma
4. Listo
```

Para publicar tu propia versión en GitHub Pages:

```text
Settings → Pages → Deploy from a branch
```

Selecciona la rama `main` y la carpeta raíz `/`.

## ⚖️ Importante

Esta herramienta permite insertar una **representación gráfica de una firma manuscrita** en un documento.

No genera una Firma Electrónica Avanzada (FEA), certificados digitales ni firmas criptográficas, y no pretende sustituirlos cuando una ley, contrato, institución o procedimiento exija específicamente alguno de esos mecanismos.

Es una herramienta para situaciones donde resulta apropiado utilizar una firma manuscrita o su representación digitalizada.

---

## 💡 ¿Por qué existe?

Porque para algo tan sencillo como dibujar una firma, guardarla como PNG o colocarla sobre un PDF no debería ser necesario crear una cuenta, subir documentos personales a un servidor o contratar una suscripción.

Así que la solución fue simple:

**hacer una herramienta que solamente firme.**
